# Compatibility

## Supported versions

- Paper/Folia: 1.20.1 through 1.21.11.
- Tested target: Paper/Folia 1.21.11.
- Plugin bytecode: Java 17.
- Server runtime: use the Java version required by that Minecraft release; Java 21 is normally required for Minecraft 1.20.5 and newer.

The plugin is compiled against Paper API 1.20.1 and uses stable Bukkit/Paper APIs. CraftBukkit and Spigot-only deployments are not part of the supported test matrix. Proxy platforms require a Paper/Folia backend installation.

## Support policy

Bug reports must include the plugin version, exact server software/build, Java version, relevant logs, and reproduction steps. Modified or unofficial JARs are outside the support scope.

# 兼容性

## 支持版本

- Paper/Folia：1.20.1 至 1.21.11。
- 测试目标：Paper/Folia 1.21.11。
- 插件字节码：Java 17。
- 服务端运行环境：请使用对应 Minecraft 版本要求的 Java；Minecraft 1.20.5 及以上通常需要 Java 21。

插件基于 Paper API 1.20.1 编译，并使用稳定 Bukkit/Paper API。纯 CraftBukkit、Spigot 环境不在测试范围内；代理架构需要在 Paper/Folia 后端安装。

提交问题时必须包含插件版本、准确的服务端软件/构建号、Java 版本、相关日志与复现步骤。修改过或来源不明的 JAR 不在支持范围内。
