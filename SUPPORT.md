# Support

Before requesting help, install the latest official Release, read `README.md` and `docs/`, and reproduce with an unmodified configuration where practical.

Use [GitHub Issues](https://github.com/Lazyzouo/IPTMUTECHAT/issues) for confirmed bugs and feature requests. Include plugin version, Paper/Folia build, Java version, operating system, reproduction steps, expected/actual behavior, and sanitized logs.

Never post IP records, credentials, private-message content, or other personal data. General Minecraft server administration and unofficial builds are outside project support.

# 支持

请求帮助前，请安装最新官方 Release，阅读 `README.md` 与 `docs/`，并尽量使用未修改的配置复现。

已确认错误和功能建议请使用 [GitHub Issues](https://github.com/Lazyzouo/IPTMUTECHAT/issues)。必须提供插件版本、Paper/Folia 构建、Java 版本、操作系统、复现步骤、预期/实际行为及脱敏日志。

严禁公开 IP 记录、凭据、私聊内容或其他个人数据。通用 Minecraft 服务器管理和非官方构建不属于项目支持范围。
