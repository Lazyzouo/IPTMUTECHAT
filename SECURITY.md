# Security Policy

## Supported version

Only the latest stable GitHub Release receives security updates. Deploy official Release assets and verify the published SHA-256 checksum.

## Reporting

Do not disclose vulnerabilities in public issues. Use [GitHub private vulnerability reporting](https://github.com/Lazyzouo/IPTMUTECHAT/security/advisories/new) with affected versions, impact, reproduction steps, and a minimal proof of concept. Do not include unrelated player IP records or credentials.

The maintainer will acknowledge a valid report when available, investigate impact, prepare a fix, publish a security advisory, and credit the reporter unless anonymity is requested.

---

# 安全策略

仅最新稳定 GitHub Release 接收安全更新。请使用官方 Release 资产并核对公开的 SHA-256。

请勿在公开 Issue 披露漏洞。使用 [GitHub 私密漏洞报告](https://github.com/Lazyzouo/IPTMUTECHAT/security/advisories/new)，提供受影响版本、影响范围、复现步骤与最小证明；不要附带无关玩家 IP 或凭据。

维护者会在可处理时确认有效报告、评估影响、准备修复并发布安全公告；除非报告者要求匿名，否则会注明贡献。
